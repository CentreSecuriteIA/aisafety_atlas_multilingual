**FR**
Répertoire contenant les ressources traduites automatiquement et utilisées pour la génération du site multilingue :
- les fichiers JSON générés automatiquement par la commande `docusaurus write-translations`;
- les fichiers markdown traduits automatiquement avec l'outil de traduction automatique, obentenus à partir des fichiers markdown originaux en anglais dans `./docs`, ainsi que les fichiers des médias nécessaires;
- les fichiers JSON de contenu centralisés, traduits automatiquement à partir des fichiers dans `./src/data'. A noter que cette étape est composée de deux parties : la traduction des fichiers des glossaires, et la traduction des autres fichiers JSON.

La structure principale de ce répertoire est la suivante :
```
./i18n
└── fr
    ├── docusaurus-plugin-content-docs
    │   └── current
    ├── docusaurus-plugin-content-pages
    │   └── data
    └── docusaurus-theme-classic
```

**EN**
Directory containing automatically translated resources and used for generating the multilingual site.
- JSON files automatically generated by the `docusaurus write-translations` command;
- Markdown files automatically translated using the automatic translation tool, obtained from the original English Markdown files in `./docs`, as well as the necessary media files;
- centralised content JSON files, automatically translated from the files in `./src/data`. Note that this step consists of two parts: translating the glossary files in one hand, and translating the other JSON files in the other hand.

The main structure of this directory is as follows:
```
./i18n
└── fr
    ├── docusaurus-plugin-content-docs
    │   └── current
    ├── docusaurus-plugin-content-pages
    │   └── data
    └── docusaurus-theme-classic
```
